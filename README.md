# Findr

Search across your work apps (Google Drive, Slack, Gmail, …) from one search bar, and ask questions that are answered with citations back to the original sources. Each user only sees content they can already see in the source app.

Design docs live in [architecture/](architecture/). Current status: **phase 0 (foundation)**: sign-in, workspaces, CI.

## Layout

```
backend/     Fastify API + background worker (TypeScript)
  src/api/        routes, plugins, server entry point
  src/auth/       access tokens, refresh-token rotation, Google sign-in
  src/db/         Drizzle schema + database client (PGlite or Postgres)
  src/workspaces/ workspace service
  src/worker/     worker entry point (queues arrive in phase 1)
  migrations/     SQL generated by drizzle-kit
  tests/          Vitest tests (run against in-memory PGlite)
frontend/    React + Vite web app
architecture/ design documents
```

## Run it locally (no Docker)

Requires Node 22+ and pnpm.

```sh
pnpm install
cp backend/.env.example backend/.env
pnpm --filter backend gen:keys      # paste the two printed lines into backend/.env
pnpm dev                            # API on :3000, web app on http://localhost:5173
```

The database is [PGlite](https://pglite.dev), real Postgres compiled to WebAssembly, stored in `backend/.data/`. Nothing to install. Delete that folder to reset.

With `DEV_LOGIN_ENABLED=true` you can sign in with any email address. To use Google sign-in, set `GOOGLE_CLIENT_ID` and `GOOGLE_CLIENT_SECRET` (see `.env.example`).

## Common commands

| Command                             | What it does                                 |
| ----------------------------------- | -------------------------------------------- |
| `pnpm dev`                          | Run API and web app with hot reload          |
| `pnpm test`                         | Run all tests                                |
| `pnpm lint` / `pnpm typecheck`      | Static checks (CI runs these on every PR)    |
| `pnpm format`                       | Format all files with Prettier               |
| `pnpm --filter backend db:generate` | After editing `schema.ts`: write a migration |
| `pnpm --filter backend db:migrate`  | Apply migrations to `DATABASE_URL`           |

## API (phase 0)

| Method | Path                  | Notes                                            |
| ------ | --------------------- | ------------------------------------------------ |
| GET    | `/healthz`, `/readyz` | Liveness; readiness also checks the database     |
| GET    | `/v1/auth/providers`  | Which sign-in methods are enabled                |
| GET    | `/v1/auth/google`     | Starts Google sign-in (OIDC + PKCE)              |
| POST   | `/v1/auth/dev-login`  | `{ email }`, development only                    |
| POST   | `/v1/auth/refresh`    | Rotates the refresh cookie, returns access token |
| POST   | `/v1/auth/logout`     | Revokes the session                              |
| GET    | `/v1/me`              | Current user and workspaces                      |
| POST   | `/v1/workspaces`      | `{ name }`                                       |
| GET    | `/v1/workspaces/:id`  | Members only                                     |
| PATCH  | `/v1/workspaces/:id`  | `{ name }`, owners and admins only               |
